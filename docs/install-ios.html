Install on iPhone

Open this page in Safari on the device, not in another browser or an app: itms-services:// links only work from Safari. The build is ad hoc: it installs only on a device that is registered in its provisioning profile. If iOS says the developer is untrusted, trust it in Settings → General → VPN & Device Management.
