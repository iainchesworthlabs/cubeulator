**Releases are published by the shared release workflow of the organisation.** A release is made only after the owner approves it, its signatures are checked against the public key in the repository before anything is published, and the Windows program and installer can be test-signed. The key is no longer attached to each release: take it from `docs/signing-key.asc` in the repository and compare its fingerprint with the one in [the verify page](docs/guide/verify.md). Windows still asks before it runs the installer, because the test certificate is trusted only on the owner's own machines.
