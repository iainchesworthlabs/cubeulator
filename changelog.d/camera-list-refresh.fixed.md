**The list of cameras catches up when you allow the camera while it is still loading.** In the browser the cameras' real names are given only once you have allowed the camera, and the app reads the list again then. If you allowed it while the first read was still going, the second read was lost, so Settings and the **Switch camera** button could keep "Back camera" and "Front camera" instead of your cameras. The app now keeps that request and reads the list once more as soon as the first read ends, with the camera you chose still chosen. A read that never finishes is given up on after a minute, so **Look again** works again instead of Settings saying "Looking for cameras…" for ever.
