**The graphics API can no longer stop Cubeulator starting.** The window's graphics API (Direct3D 11, Vulkan, ...) can be set for one launch with `--graphics-api=<name>` or `CUBEULATOR_GRAPHICS_API`, or for good in Settings; the application checks that the one it is about to use can start on the machine, falls back down a list of others if it cannot, and remembers an API that crashed it so the next launch goes past it. On Windows a machine with no working GPU driver now opens on Direct3D 11's software renderer. See [Graphics API](docs/graphics-api.md).
