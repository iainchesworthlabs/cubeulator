**Cubeulator draws with Vulkan by default on Windows and Linux.** Vulkan takes less of the GPU for each frame and draws the scan screen about a third faster; it starts about 150 ms later and holds about 100 MB more graphics memory. A computer that cannot use Vulkan opens on Direct3D 11 (Windows) or OpenGL (Linux) without being asked, and *Settings > Rendering* still picks any other. See [Graphics API](docs/graphics-api.md).
