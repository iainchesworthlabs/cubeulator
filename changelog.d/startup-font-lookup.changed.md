**The app starts a little faster where its fonts are not installed.** The interface is set in Archivo and IBM Plex Mono, and a machine that does not have them has Qt look through every font it has before it falls back to its own, which the first text used to wait for. That lookup now runs on a thread of its own while the screens are built: about 50 ms less before the first screen on the machine it was measured on, with the text set in the same faces as before in all nine languages. See [Performance](docs/performance.md#what-was-not-fixed).
