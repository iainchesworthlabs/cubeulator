**The profiling build uses Tracy 0.14.1.** The vcpkg manifest pins the `tracy` port to at least 0.14.1 and moves the built-in baseline up to the checked-out registry, whose port build turns `TRACY_ENABLE` on for the client library (upstream flipped its default off in 0.14.0, so the older baseline produced an empty client). The build gains execution sections (the trace now marks *startup* and each *solve*), `tracy-capture-daemon`, a rewritten D3D12 backend and WebGPU support; the capture tools and the client come from the same release, so a trace stays consistent from recording to export.
