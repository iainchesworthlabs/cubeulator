**Building: one vcpkg can be shared between checkouts.** Set `ICL_VCPKG_STORE` to a directory and every checkout, worktree and repository that carries the same module reuses one vcpkg checkout per pinned commit, instead of each keeping its own copy of `deps/vcpkg` or pointing it at a shared directory with a junction. A fresh clone and CI are unchanged. A `deps/vcpkg` that is a dead link now fails with a message that names the link and its missing target, and a build directory whose vcpkg pin moved says to configure again with `--fresh`. See [Getting started](docs/getting-started.md#sharing-vcpkg-between-checkouts).
